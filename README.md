# Dichotomy: playtest builds

Thanks for trying **Dichotomy**, an early prototype of a top-down stealth game where every mirror is a door into the building reflected across its glass.

## Download the newest build

These links always give you the newest playtest:

- **Windows:** [Dichotomy-windows.zip](https://github.com/NoctuaeSophos/dichotomy-playtest/releases/latest/download/Dichotomy-windows.zip)
- **Linux:** [Dichotomy-linux.zip](https://github.com/NoctuaeSophos/dichotomy-playtest/releases/latest/download/Dichotomy-linux.zip)

Unzip it and open **READ ME FIRST.txt**. It says how to start the game, what to try, and what feedback would help most. Keep every file from the zip together, because the game needs the library next to it.

Windows may warn that the app is unrecognised, because it isn't signed. Click "More info", then "Run anyway". You need a graphics card with Vulkan.

Older builds are listed under [Releases](https://github.com/NoctuaeSophos/dichotomy-playtest/releases).
